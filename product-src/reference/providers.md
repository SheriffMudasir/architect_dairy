# Providers

Selected in `studio.config.json` (written by `npm run setup`). Keys come only from environment
variables (`.env`). Each provider lives in `scripts/providers/*.mjs` — small and readable.

## Voice (`voice.provider`)

| Provider | Key | Captions | Notes |
|---|---|---|---|
| `elevenlabs` | `ELEVENLABS_API_KEY` | exact (returns per-character timestamps) | `voice.elevenlabs`: `voiceId`, `model` (default `eleven_multilingual_v2`; use whichever model your plan offers), `stability`, `similarity`, `style`, `speed` |
| `gemini` | `GEMINI_API_KEY` | aligned from pauses | `voice.gemini`: `model` (default `gemini-3.8-flash-tts`), `voice` = built-in name (e.g. `Kore`) or a designed `voice_…` id; or `design.prompt` to create a new voice on first run (id is saved back to the config) |
| `openai` | `OPENAI_API_KEY` | aligned from pauses | `voice.openai`: `model` (default `gpt-4o-mini-tts`), `voice`, `instructions` |
| `file` | none | aligned from pauses | put `public/<ep>/audio-src/<beat-id>.(wav|mp3|m4a)` — recorded, or generated by any tool |

All clips are trimmed, loudness-normalised to −14 LUFS and stored as `public/<ep>/audio/<beat>.wav`.
Provider timestamps are saved next to them (`<beat>.words.json`) and preferred for captions.

**Agent-tool mode (no keys):** if your agent has its own text-to-speech tool (for example an
ElevenLabs or MiniMax tool from a tool marketplace), set `voice.provider` to `file`, generate each
beat's `text` exactly as written with that tool, save it as `public/<ep>/audio-src/<beat-id>.mp3`,
then run `npm run voice -- <ep>`. Same for music: save a track as `public/<ep>/music-src.mp3` with
`music.provider: file`. Tell the user what each tool run costs if the tool reports a price.

## Music (`music.provider`)

| Provider | Key | Notes |
|---|---|---|
| `lyria` | `GEMINI_API_KEY` | `music.lyria.model` (default `lyria-3.5`). Prompt is built from the episode's `music` plan with real timestamps |
| `elevenlabs` | `ELEVENLABS_API_KEY` | instrumental, length = episode length (capped by `music.elevenlabs.maxSeconds`) |
| `file` | none | `public/<ep>/music-src.(mp3|wav|m4a)` — must be licensed for the user's use |
| `none` | — | voice + sound effects only |

Music is trimmed to the episode, faded out, normalised to −20 LUFS and ducked under the voice
(`src/shared/Soundtrack.tsx`: 0.15 under speech, 0.28 in gaps, 0.10 on `dips` beats).

## Stock media (`media.providers`, any combination)

| Provider | Key | Photos | Video | Licence recorded |
|---|---|---|---|---|
| `openverse` | none | ✓ (CC0/BY/BY-SA filtered) | — | CC licence + creator + source link |
| `pexels` | `PEXELS_API_KEY` | ✓ | ✓ (portrait) | Pexels License |
| `pixabay` | `PIXABAY_API_KEY` | ✓ | ✓ | Pixabay Content License |
| `wikimedia` | none (set `media.wikimediaContact`) | ✓ (CC/PD filtered) | — | licence + author + file page |

`npm run media -- <ep> search "<q>" [n] [--provider p] [--video]` then
`npm run media -- <ep> get <provider:id> <name>`. Photos → `public/<ep>/media/<name>.jpg`
(≤ 2000 px); videos → `<name>.mp4` (1080 wide, 30 fps, silent, ≤ 12 s).

## Transcription check (`transcribe.provider`)

`elevenlabs` (Scribe), `openai` (Whisper), `gemini`, or `none`. Empty = reuse the voice
provider's key where possible. Used only by `npm run check-voice`.

## Adding a provider

Copy the closest function in `scripts/providers/*.mjs`, keep the same return shape, register
it in the `get…` switch, add its key variable to `KEY_VARS` in `scripts/lib.mjs`, a ping to
`scripts/doctor.mjs`, and a flag to `scripts/setup.mjs`. Document its endpoint at the top of the file.
